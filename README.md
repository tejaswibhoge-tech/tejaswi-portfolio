# Bhoge Tejaswi — Portfolio

Responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — lavender, white and deep-purple theme
- `script.js` — mobile navigation and current year
- `assets/certificates/` — the two supplied Wolfram U certificate PDFs

## Preview
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Upload all files and folders from this package to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site; the URL will appear on the Pages screen.

Before publishing, verify the skills and project descriptions. The two projects are clearly labelled as academic concepts; update them to match the student's actual work.
